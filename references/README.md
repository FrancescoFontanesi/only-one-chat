# references/

Copie locali, in sola lettura, di repository esterni usati **solo come studio**.

- Si recuperano con `scripts/fetch-references.ps1` (commit fissati).
- Sono esclusi da git (solo questo README è versionato) e dal VSIX.
- Non sono codice del progetto: non si importano, non si installano, non si eseguono.
- Il progetto compila e si testa anche se questa cartella viene cancellata.
